# Finished Work Archive

This archive stores artifacts after their task purpose is complete or their guidance is superseded. These files preserve dated decisions, scope, implementation evidence, and handoffs; they are not current implementation instructions. Follow the active migration PRD and current source for present behavior.

## Categories

- [Completed task prompts](tasks/README.md)
- [Completed and historical specifications](specs/README.md)
- [Completed implementation reports](implementation/README.md)
- [Completed handovers](handovers/README.md)

When archiving an artifact, choose the category by its primary purpose, preserve its date and historical status, and update inbound links and `docs/README.md`.
